# 四站分类对照（一级 / 二级）

四站的分类体系名字不同、粒度不同，想跨站找「同一类模型」先得有一张对照表。
这里放三份东西：

| 文件 | 是什么 |
| --- | --- |
| `sites.json` | 原站抓取快照：四个站各自的一级分类 + 它下面的二级分类（带站点自己的 id） |
| `merge.json` | 人工归并结果，**唯一权威**。左边统一分类，右边是各站对应的分类 id |
| `对照表.md` | 由上面两份生成的表格，给人看；改了 `merge.json` 就重新生成，别手改 |

```sh
node cats.mjs            # 抓四站 → 覆盖写 sites.json
node cats.mjs --table    # 校验覆盖 + 重新生成 对照表.md（不联网）
node --test test.mjs     # 覆盖校验也在自检里（不联网）
```

## 各站分类从哪来

| 站点 | 位置 | 一级 / 二级 |
| --- | --- | --- |
| 创想云 | `model-category/3d-print-all` 页的 `__NUXT_DATA__` → `data.modelCategoryBaseData.categories` | 10 / 45，自带中英文名 |
| Snapmaker | `/zh/models` 页 RSC 载荷里的 `categories`（根节点「场景分类」） | 10 / 56 |
| MakerWorld | `makerworld.com.cn/zh/3d-models` 页面 DOM 的 `/zh/3d-models/<id>-<slug>` 链接（整站挡非浏览器 UA，只能借浏览器读） | 11 / 70 |
| MakerOnline | `/zh/allModel/all/all/0.html` 的 `window.__NUXT__` → `data[0].categoryData`（自带 level 1/2） | 14 / 69 |

`makerworld.com` 国际站会把国内 IP 引到 `makerworld.com.cn`，两份数据同源，抓国内站。

## 归并规则

1. **同名直并**：四站都叫「微缩模型 / 微型模型」的，直接一行。
2. **同义并**：`珠宝 / 戒指 / 耳环`（MakerWorld 拆三份）→ 一行「珠宝首饰」，因为其余三站都只给一个首饰类目；
   `包 / 箱包 / 包袋与钱包` → 一行；`桌游 / 棋盘游戏` → 一行。
3. **跨一级移位**：原站挂在别的一级下、语义相同的，并过来并在表里标「（在「X」下）」。
   例：创想云没有独立「工具」一级，`工具与零配件` 挂在「日用家居」下 → 并进「工具/手工工具」；
   MakerWorld、MakerOnline 的 `收纳工具 / 整理收纳` 挂在「工具」下 → 并进「家居与生活/收纳整理」。
4. **一个源分类可以横跨两个统一分类**：创想云 `电子与遥控` 同时算「电子」和「遥控模型与无人机」，
   `服装鞋帽` 同时算「服装」和「鞋履」。同一行内不重复，跨行允许。
5. **「其他」不跨站并**：每站「其他」的语义随它的一级分类走，只在对应行里出现。

## 几个判断，以及为什么

- **收纳整理放在「家居与生活」而不是「工具」**：4 站里有 3 站挂在工具下，但内容都是桌面/家居收纳；
  放家居更贴近实际用法，表里用「（在「工具」下）」标出原站位置。
- **角色扮演单独成一级**：3 站有一级（Snapmaker / MakerWorld / MakerOnline），创想云只有 `时尚/Cosplay` 一个二级，
  并进「角色扮演与道具/角色扮演服装」。
- **「微缩模型 / 玩具 / 流行文化」里的「角色」不合并**：MakerOnline 三处都有「角色」，
  但载体不同（微缩是桌面小比例、玩具是可动人偶、流行文化是 IP 梗图），合并会丢语义，保持三行各自对应。
- **医疗**：创想云有「医疗与健康」一级，MakerOnline 有「健康与健身」，MakerWorld/MakerOnline 的「医疗工具」
  留在「工具」下（多数站把它当工具），不硬拉进医疗一级。
- **生成器**：创想云的 `MakeNow`、MakerWorld 的「生成器模型」、MakerOnline 的「生成式3D模型」并成一级；
  Snapmaker 没有对应分类。MakerOnline 的「创意套件模型」没有二级，按一级并入「玩具与游戏」。

## 覆盖情况

统一分类 13 个一级、96 个二级，四站的原站分类 100% 被收录（`node --test test.mjs` 会卡住这件事）。
缺口是站点自身的：Snapmaker 无生成器类、MakerWorld 无医疗一级、创想云无独立工具/角色扮演一级。
