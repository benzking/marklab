# 0005 · 控制台模块：范围、口径、限速

- 状态：已采纳（2026-10-29）
- 相关：0001（登录态）、0002（playwright-core）、0003（匿名优先）、0004（重复检测）

## 决策

控制台是独立页面 `/console`，不塞进现有 `index.html`。它负责四件事：
工作台数据、登录态看板、订阅、抓取任务。

### 1. 时间口径

**北京时间自然日，00:00 切。**

「今日入库 / 7 日 / 30 日」按 `model.json` 的 `fetchedAt` 落在哪个自然日算。
不用 24 小时滑动窗口，也不用 UTC。

复核时实测过三种口径的差距，同一个「今日」能算出 29 / 137 / 138：

| 口径 | 今日 |
|---|---|
| UTC 日期切片 | 29 |
| 北京时间自然日 | 137 |
| 24 小时滑窗 | 138 |

### 2. 磁盘占用

实测全量遍历 `library/`（2252 个文件 / 4.74 GB）耗时 **74 ms**（热缓存），
不需要任何优化，只需 60 秒缓存防止连点。

当前构成（2026-10-29）：`files/` 3.08 GB、`img/` 1.66 GB。
图片占了 35%（1.66 GB / 1729 张，jpg 约 1 MB 一张），是压缩的真实候选。

### 3. 搜索限速

下载限速是模型之间 60–120 秒 + 模型内每文件 5–10 秒（AGENTS.md 不可省）。搜索是另一条通道：

- 单站 **每分钟不超过 10 次**，两次间隔 **不少于 6 秒**（ADR-0008 起与聚合搜索共用这一份配额）
- 按站点各自计时，不共享配额
- 订阅一轮跑完所有关键字时排队，不并发
- 手动动作（聚合搜索）插到队头，见 ADR-0008 §5

### 4. 大模型打标签

- 接入 OpenAI 兼容协议，`LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL`，
  凭据存 `~/.marklab/llm.json`（chmod 600），不进仓库
- 打标签时**提示词限定只能用已有标签**；模型想造新词必须进
  `data/tag-pending.json` 等用户确认，确认后才进标签池
- 已有标签直接复用，不重复问

### 5. 重复模型的主记录

- **先入库的为主记录**（同站标题+作者即确认重复；跨站标题+作者先记疑似，作者件 sha256 撞上才确认）
- 判据：元数据级（标题 + 作者）抓取前拦；文件级只看作者件的 sha256，且只在跨站疑似时用

### 6. 控制台不做鉴权（先）

监听保持 `0.0.0.0`，不加密码。已知风险：同一局域网内任何人打开 `/console`
都能触发下载、改订阅、看登录态。要加密码时另起 ADR。

## 后果

- **好处**：口径写死，数字不会因为时区/窗口定义漂移；限速两条通道分开，
  订阅不会把下载的配额吃掉
- **代价**：`/console` 在局域网里是开放的；图片占 1.66 GB 暂时不处理

## 实现时补的两条（实测踩出来的）

### 7. 登录态走独立接口，不塞进工作台

`session.state()` 冷启动要开浏览器标签、等 hydrate，实测 **12.8 秒**；塞进
`/api/console/workbench` 会让首屏十几秒白屏。所以拆成 `/api/console/login`，
页面先渲染其余数据、登录态那块显示「检测中…」。拆开后工作台降到 **782 ms**。

### 8. `grab.mjs` 必须自己退出

`playwright-core` 的 CDP WebSocket 会撑住 Node 事件循环，抓完进程不退出。
表现很阴：子进程一直活着 → 任务永远停在 `downloading`、`endedAt` 一直是 null，
但进度事件看起来已经「完成」了。所以 `grab.mjs` 结尾统一走
`process.stdout.write('', () => process.exit(0))`——先冲干净 stdout 再退，否则日志被截断。

顺带：文件一个都没下到时打一条 `warning` 事件，任务里显示「文件没下到（多半是站点要求登录态）」，
不再静悄悄算成功。

### 9. 批抓也走同一个任务队列

`bulk.mjs` 原来自己 `spawn grab.mjs`，控制台完全看不见它。改成
`tasks.enqueue({ url, source: 'bulk' })`：批抓的 60–120 秒间隔不变，但每条都有任务记录、
进度、失败原因，和手动/订阅走一套逻辑。

代价是任务队列现在跨进程：`bulk.mjs` 是独立进程，写进同一个
`data/tasks/YYYY-MM.jsonl`，而常驻 `server.mjs` 的 `tasks` Map 看不见。
所以 `tasks.refresh()` 按**字节增量**把新增的行并进内存（记住读到哪个偏移，
半行留到下次），控制台轮询任务/工作台时调一次。不整文件重读，月份文件再大也只有增量成本。

10. **任务可以插队 / 停止 / 重试**。排队中的任务能挪到队首（下一个就跑它），也能直接移出队列；在跑的任务 kill 掉子进程后标「已停止」并不再重排（否则下一轮又自己跑起来）。重试只对已结束的任务开放。
11. **抓取子进程退出前必须关掉自己开的标签页**。`page(site)` 建的页在子进程退出后仍留在用户 Chrome 里，跑几十次就堆出几十个标签，CDP 握手随之变慢、最后报超时。`grab.mjs` 的 `exit()` 先 `closePages()`（最多等 3 秒）再退出。
